# Personal IP Generator Skill

用于 Codex 的个人 IP、头像、表情包和照片插画 Skill。支持选择画风、锁定人物与服饰特征、保持多张图的画法一致，以及只修改指定局部。

## 两种创作流程

- **个人 IP 探索**：保留原有流程——IP 类型 → 风格 → 特征与配色 → 计划确认 → 一张 3×2 六款编号预览 → 选择方案 → 正式头像和九宫格表情包。默认交付一张 4×3 成品板，可选九张透明底表情贴纸。
- **照片转插画**：按原照片逐张转绘，保留人数、各自特征、姿势、衣服与配饰；每个场景单独导出完整图片。无需先走六款头像预览。继续同一系列或局部修改时沿用已确认的设定。

编号和中文说明由宿主合成，避免依赖图像模型生成文字。透明导出需实际检查 alpha 数据及边缘。

## 安装

将本仓库克隆到 Codex skills 目录：

```bash
git clone https://github.com/ugoneliu/personal-ip-generator.git \
  ~/.codex/skills/personal-ip-generator
```

在 Codex 中使用 `$personal-ip-generator`，或请求创建个人 IP、头像、表情包、照片插画。

## 可选画风

原有五套预设保持独立，新增童趣手绘绘本风文字预设；它不会覆盖所有用户的默认画风。

| ID | 名称 | 主要特征 | 参考形式 |
| --- | --- | --- | --- |
| `caihui-feng` | 彩绘风 | 温暖纸张感、圆润角色、柔和表情 | 内置图片 |
| `xian-tiao-feng` | 线条风 | 黑白线稿、极简五官、留白构图 | 内置图片 |
| `3d-feng` | 3D 风 | 潮流 3D、柔和材质、立体光影 | 内置图片 |
| `illustration-feng` | 插画风 | 平面色块、人物插画、利落轮廓 | 内置图片 |
| `figure-feng` | 手办风 | 收藏手办质感、立体造型、产品级陈列 | 内置图片 |
| `tongqu-huiben-feng` | 童趣手绘绘本风 | 稚拙多样造型、蜡笔油画棒／色铅笔／水粉笔触、纸纹、鲜活柔和复古配色 | 文字预设，无内置预览 |

完整约束见 [references/style-presets.md](references/style-presets.md)。童趣手绘绘本风来自用户明确描述的《Mysterious Things》参考特征及纠错经验，详见 [references/storybook-style.md](references/storybook-style.md)。本仓库未附该参考原图或个人成品；精确跟随某张参考图时，需要实际提供并检查该图。它不等同于给数字卡通叠加噪点滤镜，也不要求所有人使用同一张圆脸。

也可使用 `自定义风格`：上传至少一张有权使用的风格图，提取本次任务的风格锁，默认不存入仓库。

## 使用示例

以下为文字示例，不包含真实人物素材：

- “用线条风给我做个人 IP，先看六款方案。”——进入原有 IP 向导。
- “把这三张照片转成童趣手绘绘本风，保留各自人物和衣服，每张单独导出。”——建立照片编号与逐人清单，逐图转绘与检查。
- “这张也用上一张确认的画风。”——复用风格锁，以新照片决定人物、服装和场景。
- “只把胸前图案改成库洛米头像，头饰和其他地方都保持。”——以当前已接受图片为底图，只开放胸前图案区域，并检查是否误改其他部分。

原照片和最新明确纠正决定内容，选中的风格参考决定画法，已接受作品用于保持画风连续。不会从风格参考偷带人物、猫狗、文字或道具；原照片中明确要求保留的服装图案与配饰则属于内容清单。

## 使用与素材授权

- 仅使用用户提供或有权使用的肖像与参考素材。不将用户肖像、个人成品或任务清单写入 Skill。
- 风格参考仅提供抽象视觉语言；不复制其中的人物、文字、商标、构图或场景。用户明确要求保留的原照片服饰图案按内容清单处理。
- 保存风格描述不代表可以公开原图。添加、替换或再发布参考图片前，需要相应授权。
- 生成后需实际检查图片与导出文件。最多进行两次定向修复，仍有问题就说明未解决的细节；不以工具成功返回代替质量验收。
